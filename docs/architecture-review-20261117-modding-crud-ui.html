Problem

Content registration mutates global tables across seven one-shot bootstrap files, leaving no seam to create, toggle, reorder, or delete mods without editing base .bin files.

Solution

Consolidate manifest CRUD, compilestring() script evaluation, reversible g_*_defs table overlays, and skin/item cache rebuilds inside one deep ModCatalog module.

Wins

  • Locality: CRUD concentrates in one module
  • Leverage: one interface feeds four callers
  • Two adapters make mod CRUD testable
  • Runtime compilestring() skips .bin rebuilds

Problem

Updating or deleting a mod breaks raw StateObject blobs in global save.dat slots while modded runs leak straight into vanilla PlayerProfile and Steam achievements.

Solution

Deepen SaveManager and PlayerProfile behind one persistence module that partitions slots by active mod digest, validates required manifests on resume, and gates Steam sync.

Wins

  • Locality: slot isolation in one module
  • Mod deletes never corrupt vanilla saves
  • Steam feats stay gated behind seam
  • Two adapters test blobs without Steam
Worth exploring ports & adapters

Problem

Static register_state_class layouts and unverified presynchronize / replay.dat blobs trigger instant state_crc desyncs when peers run different mod sets.

Solution

Introduce a deep ModSession module that packs mod state into a pre-registered StateObject slot, stamps digests into lobbies and replays, and aligns peer loadouts before join.

Wins

  • Locality: schema and CRC stay aligned
  • Leverage: one handshake guards co-op, replays
  • Catches mod mismatch before rollback desync
  • Loopback adapter tests peer sync offline

Problem

Native asset loaders read data/*.png, *.ogg, and *.bin straight from the install folder while Squirrel File writes lack directory enumeration in user:Rampage Knights.

Solution

Place a deep native overlay module at the PE32 DLL seam (unsigned binary, CFG disabled) to overlay user:Rampage Knights/mods/ paths and expose four directory CRUD verbs to Squirrel.

Wins

  • Locality: path overlay behind one seam
  • Base .nut.bin files stay untouched
  • Interface shrinks to four file verbs
  • Stand-in adapter tests CRUD in memory
